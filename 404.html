📱 Cómo obtener la IP de Phyphox:

1. Abre Phyphox → selecciona «Aceleración (sin g)»
2. Pulsa ▶ para iniciar la grabación
3. Toca el menú ⋮ (arriba a la derecha)
4. Selecciona «Acceso remoto» → activa el interruptor
5. Phyphox muestra una dirección tipo http://192.168.1.45:8080
6. Escribe solo la parte 192.168.1.45:8080 en el campo de arriba

⚠️ El móvil con Phyphox y este dispositivo deben estar en la misma WiFi.
Abrir como file:// o HTTP local — no HTTPS.

Sin Phyphox → usa Modo Demo con datos sintéticos.
